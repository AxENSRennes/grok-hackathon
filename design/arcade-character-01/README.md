# First character: cyan hoodie

`cyan-hoodie-poses-v1.png` is a proposal generated with the built-in imagegen tool from the selected arcade family. Twelve poses: front, left side, right side, back; idle and two steps per direction. The character wears a cyan hoodie, dark pants, and white sneakers, without accessories.

The file has an alpha channel. The user explicitly approved the visual style. The grid and anchors still need normalization, and movement must be checked in the engine before this becomes a production atlas. Recoloring and accessories are not yet integrated.

Prompt and provenance: `prompt.json`. Proposed pipeline: `../arcade-sprite-pipeline.md`.
