# Premier personnage : hoodie cyan

`cyan-hoodie-poses-v1.png` est une proposition générée par l'outil intégré imagegen à partir de la famille arcade sélectionnée. Douze poses : face, profil gauche, profil droit, dos ; repos et deux pas par direction. Le personnage porte un hoodie cyan, un pantalon sombre et des baskets blanches, sans accessoire.

Le fichier possède un canal alpha. Le style visuel a été explicitement validé par l'utilisateur (« c'est top visuellement »). La grille et les ancrages doivent encore être normalisés et le mouvement vérifié dans le moteur avant d'en faire un atlas de production. La recoloration et les accessoires ne sont pas encore intégrés.

Prompt et provenance : `prompt.json`. Pipeline proposé : `../arcade-sprite-pipeline.md`.
