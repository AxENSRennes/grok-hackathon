# Speech bubbles in the game renderer

`speech-bubbles-in-game.jpg` is a browser screenshot of the actual Phaser arena renderer, using the live-game character scale and two local sample messages. It is not generated concept art or evidence of a networked chat session.

Open `http://localhost:5173/preview?bubbles=1` and press B to show the sample messages for four seconds. The regular preview is unchanged, and this shortcut exists only in the local art preview. Live rooms still receive messages through the existing server chat handler.

Type checking passed. The two bubbles were visually verified above their respective characters in the browser before capture.
