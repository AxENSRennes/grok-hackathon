# Vidéo de présentation du hackathon

Installation Remotion indépendante de l'application de jeu.
Le contenu, le format et le scénario de la vidéo seront définis plus tard.

Depuis ce dossier :

```sh
npm install
npm run check:versions
npm run browser:ensure
```

Une fois les compositions créées, le CLI sera accessible avec `npm run remotion -- <commande>`.
